# Sift Dimension Mod

Adds a unique Sift Dimension to Minecraft with a custom portal and biome.

## Features

- Adds a new dimension called Sift Dimension
- Includes a custom portal block to travel to the dimension
- Features a unique biome with custom visual effects

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the mod JAR file.
2. Place it in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

1. Craft the Sift Portal block using the specified recipe.
2. Place the portal block to create a gateway to the Sift Dimension.
3. Step through the portal to explore the new dimension.

## Configuration

The mod does not have a configuration file. All settings are hardcoded within the mod.
